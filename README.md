## Benzene

Currently the project is still WIP 
I have implemented fibers with userspace context switching and `yield()`

Its an exploratory project for what would eventually be a full backend focused language

- [x] Fiber Creation
- [x] Context switching
- [x] Cooperative `yield()`
- [ ] Scheduler still in devlopment
- [ ] I/O intgreation
- [ ] Language frontend
- [ ] Memory Managment

## How to Get Started

1. Get [zig](https://ziglang.org) the latest verion from [zvm](https://zvm.app)
2. Clone the repo.
3. Run `zig build run` to run the demo main.
